# Urban Child Skills

이 폴더는 `urban-prototyping-coach`의 child skill 세트입니다.

- `urban-scope`: 문제를 줄이는 skill
- `urban-service-loop`: 서비스 루프를 정리하는 skill
- `urban-prototype`: 작은 실험물을 정하는 skill
- `urban-demo-review`: 시연 점검 skill
- `urban-pitch`: 발표 정리 skill
- `urban-spec`: 구현 명세 skill
- `urban-plan`: 구현 계획 skill
- `urban-context-audit`: 맥락 점검 skill
- `urban-evidence-boundary`: 증거와 주장 경계를 잠그는 helper skill
